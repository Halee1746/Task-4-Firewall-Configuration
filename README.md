# Task-4-Firewall-Configuration

## Objective

Configure and test basic firewall rules using Windows Defender Firewall.

## Steps Performed

1. Opened Windows Defender Firewall.
2. Viewed existing inbound firewall rules.
3. Created a rule to block TCP port 23 (Telnet).
4. Verified the rule was active.
5. Tested the firewall configuration.
6. Removed the test rule to restore original settings.

## Outcome

Successfully configured and tested firewall rules, demonstrating basic firewall management and network traffic filtering skills.

## Firewall Summary

A firewall monitors and filters incoming and outgoing network traffic based on predefined security rules. It helps protect systems by allowing legitimate traffic and blocking unauthorized connections.
